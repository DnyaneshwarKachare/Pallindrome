# Palindrome Checker Using Stack and Queue

A Python-based DSA mini project that checks whether a given word or string is a palindrome using Stack and Queue data structures.

The project includes an attractive Graphical User Interface (GUI) developed using Python Tkinter.

## Problem Statement

To design and implement a Palindrome Checker using Stack and Queue data structures in Python. The application accepts a word or string from the user and checks whether it reads the same forward and backward.

## Objectives

- To understand Stack and Queue data structures.
- To understand LIFO and FIFO concepts.
- To check whether a given string is a palindrome.
- To implement DSA concepts using Python.
- To develop a GUI using Tkinter.

## Features

- Palindrome checking using Stack
- Palindrome checking using Queue
- Attractive Tkinter GUI
- Displays original and reversed string
- Displays Palindrome / Not Palindrome result
- Clear button to reset the input
- Simple and user-friendly interface

## Technologies Used

- Python
- Tkinter
- Collections Deque
- Stack
- Queue
